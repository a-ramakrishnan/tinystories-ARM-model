TinyStories LM Studio
Train a language model from scratch, on your Mac
    Made for Apple Silicon

    Training runs on your Mac's GPU through PyTorch's Metal (MPS) backend. No cloud, no Nvidia card needed.

    Step 1

    Choose a dataset

    Any Hugging Face text dataset works. It's downloaded once and kept in data/, so later runs start instantly.

    Presets

    Browse documents

    Step 2

    Turn text into tokens

    Models read numbers, not letters. The GPT-2 tokenizer splits text into tokens (whole words or pieces of words) and maps each one to an ID from a vocabulary of 50,257.

    Try the tokenizer

    Hover a token to see its ID. · marks a space, ↵ a newline.

    Tokenize the whole dataset

    Step 3

    Cut training batches

    Each batch is a stack of random windows of block_size consecutive tokens. The target is the same window shifted one token to the right: at every position the model learns to predict the next token.

    First window of the batch

    Same color = same token. Each target is the token that comes right after the input above it.

    Step 4

    Build the transformer

    A decoder-only transformer, like a miniature GPT-2. Bigger numbers mean a more capable model, but slower training and more memory.

    Train

    Every evaluation measures loss on training and validation data, and saves the weights whenever validation loss reaches a new low. Watch both lines go down.

    Step 6

    Generate stories

    Uses the saved checkpoint with the best validation loss. Give it the start of a story and it continues.

    Lower temperature is safer and more repetitive, higher is more surprising. Top-k only picks among the k most likely next tokens (0 = no limit).
